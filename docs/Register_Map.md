# Register Map

| Offset | Name   | Description |
|--------|--------|-------------|
| 0x00   | CTRL   | Start bit |
| 0x04   | CLKDIV | Clock divider |
| 0x08   | ADDR   | Slave address |
| 0x0C   | TXDATA | Data |
| 0x10   | RXDATA | Received |
| 0x14   | STATUS | BUSY/DONE/NACK
